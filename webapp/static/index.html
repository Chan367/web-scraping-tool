Proxy rotation (all jobs)

direct connection

Leave the list empty to use the computer's real IP. Paste one proxy per line (for example http://user:pass@1.2.3.4:8080) to use it for every new job. Credentials are hidden in logs and job commands.

What to collect

Toggles decide what is downloaded. The JSON always keeps every link the crawler finds — turn Images off and you still get the image URLs, just no image files. Click a format chip (for example svg) to include or exclude that file type; only the active chips are downloaded. Only the Text toggle changes the JSON (it drops the page body).

Crawl mode

Pick Internal for your own site (all menus and the pages inside them), External for only the other websites it links to, or Full for both. Your toggles decide what is downloaded; links are always kept in the JSON.

Re-check stored pages

Fetches pages that are already saved and rewrites only the ones whose title, text or file list changed. Off = only new pages are crawled.

De-dupe finished websites

      
When a scrape is stopped or finished, the site appears here with a
        De-dupe button. Enter the parent folder where the copy should be saved
        (for example C:\Deduped) — the app creates
        <folder>\<site>_deduped there.

      
Your original Scraped_Data\<site> folder is
        never changed. You can hand over the original (without de-dupe) or the
        separate de-duped copy. A manifest records every original file, so
        Restore full can rebuild the non-de-duplicated version later.
